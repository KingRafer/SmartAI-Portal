# Smart AI Portal

Independent Smart AI member portal (not a fork).

## Features
- Live MT5 account performance (ACC01 / ACC02 / ACC03) via SmartInvestama API
- Profit calendar
- Referral network — 5-level commission ($15 / $2 / $1 / $1 / $1 per lot)
- Dashboard, trading report, transactions, commission

## Deploy
Static site — connect this repo to **Vercel** (or GitHub Pages).

Entry: `index.html` → `login.html`

## Notes
- Referral volume and some trade logs are demo/simulation until broker lot API is wired.
- Do not share MT5 QR codes (they contain account passwords).
